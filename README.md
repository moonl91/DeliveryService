# DeliveryService

Практическая работа №1
Простой консольный симулятор службы доставки на Java.

## Требования
- JDK 21 или новее
- Visual Studio Code
- Extension Pack for Java

## Запуск из корневой папки проекта

```bash
javac -encoding UTF-8 -d out src/delivery/*.java
java -cp out delivery.Main
```

Приложение хранит данные только в оперативной памяти. После завершения программы заказы исчезают.
